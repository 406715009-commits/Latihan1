📖 หน่วยที่ 1

Maksud Kata Nama

ความหมายของคำนาม
Kata Nama ialah perkataan yang digunakan untuk menamakan orang, haiwan, benda dan tempat.
คำนาม คือ คำที่ใช้เรียกชื่อ คน สัตว์ สิ่งของ และสถานที่

ในภาษามลายู Kata Nama แบ่งออกเป็น 4 กลุ่มหลัก ดังนี้:

👤 Kata Nama Orang 🐾 Kata Nama Haiwan 📦 Kata Nama Benda 📍 Kata Nama Tempat

พลิกไปหน้าถัดไปเพื่อเรียนรู้แต่ละกลุ่มพร้อมตัวอย่างคำศัพท์กันเลย! 🌺

👤 หน่วยที่ 2

Kata Nama Orang

คำนามที่เป็นคน

ใช้เรียกชื่อบุคคลหรือคน

คำความหมาย
👩ibu = แม่
👨ayah = พ่อ
👩‍🏫guru = ครู
🧒murid = นักเรียน
👶adik = น้อง
Ibu memasak nasi.
แม่ทำอาหาร
🐾 หน่วยที่ 3

Kata Nama Haiwan

คำนามที่เป็นสัตว์

ใช้เรียกชื่อสัตว์ต่าง ๆ

คำความหมาย
🐱kucing = แมว
🐔ayam = ไก่
🐟ikan = ปลา
🐦burung = นก
🐰arnab = กระต่าย
Kucing itu comel.
แมวตัวนั้นน่ารัก
📦 หน่วยที่ 4

Kata Nama Benda

คำนามที่เป็นสิ่งของ

ใช้เรียกชื่อสิ่งของต่าง ๆ

คำความหมาย
📕buku = หนังสือ
✏️pensel = ดินสอ
🎒beg = กระเป๋า
🪑meja = โต๊ะ
💺kerusi = เก้าอี้
Ini buku saya.
นี่คือหนังสือของฉัน
📍 หน่วยที่ 5

Kata Nama Tempat

คำนามที่เป็นสถานที่

ใช้เรียกชื่อสถานที่ต่าง ๆ

คำความหมาย
🏫sekolah = โรงเรียน
🏠rumah = บ้าน
🕌masjid = มัสยิด
🏪pasar = ตลาด
🌳taman = สวน
Saya pergi ke sekolah.
ฉันไปโรงเรียน
✍️ หน่วยที่ 6

Kata Nama dalam Ayat

การนำคำนามมาใช้ในประโยค

ลองสังเกตคำนามที่ถูกไฮไลต์ไว้ในแต่ละประโยคด้านล่างนี้ — คำนามอาจเป็นคน สัตว์ สิ่งของ หรือสถานที่ก็ได้:

Ibu memasak nasi.
แม่ทำอาหาร Orang
Kucing itu comel.
แมวตัวนั้นน่ารัก Haiwan
Ini buku saya.
นี่คือหนังสือของฉัน Benda
Saya pergi ke sekolah.
ฉันไปโรงเรียน Tempat
🌺 สรุป

จำง่าย ๆ

Kata Nama = Orang + Haiwan + Benda + Tempat
👤Orang → guru
🐾Haiwan → kucing
📦Benda → buku
📍Tempat → sekolah
